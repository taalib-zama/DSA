The Facade Pattern is a structural design pattern that provides a simplified interface to a larger body of code, hiding the complexities of the subsystem. It is used to make a system easier to use by providing a unified interface to a set of interfaces in a subsystem.



Key Elements
Facade Class: The central class that exposes easy-to-use methods for complicated operations, internally delegating work to several subsystem classes.

Subsystem Classes: The collection of classes, libraries, and operations that handle the actual, and often complex, business logic.
